About Me

Hi! My name is Mike Martinescu, and I am a Software Developer and Amateur Radio enthusiast based in Vancouver, BC. I can speak English fluently, and French and Romanian in a working capacity, and I'm looking to learn Spanish!

Professional Experience

I'm currently working as a Software Developer and IT consultant. I have previous experience as a Cloud and Data Solutions Specialist for UBC's Geography Department, and as a Software Developer for Fortinet and Electronic Arts.

UBC

At UBC, I worked to help faculty, staff, and grad students with their software development and technology needs. I also ran workshops and training sessions on topics such as version control using Git, running jobs on HPC SLURM clusters, and software development using R, Matlab, or Python.

I worked on several projects while I was there:

  • Finished automating a Metashape photogrammetry workflow using Python.
  • Replaced an aging custom inventory system with a open-source solution named Snipe-IT. I also integrated it with the university's LDAP system to enable single sign-on.
  • Updated the E-Fauna BC map dashboard to use the new ArcGIS JavaScript API and to use external APIs and external GIS data layers from GBIF and Environment Canada respectively.

Fortinet

At Fortinet, I worked substantially on the FortiStack project, which was an on-premises cloud platform based on OpenStack. I also worked on two SaaS projects: SOCaaS (Security Operations Center as a Service) and MFGS (Managed Firewall Gateway Service).

Electronic Arts (EA)

At Electronic Arts, I worked as a Software Engineer on the Quality Engineering team of the Frosbite Engine. Our team was responsible for developing and maintaining software tools that ensured the quality and performance of the game engine.
